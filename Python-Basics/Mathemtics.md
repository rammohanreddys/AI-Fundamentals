# Probability Basics:

## **Random Experiment:**

A random experiment is an experiment or process that can result in multiple possible outcomes, where the exact outcome cannot be predicted with certainty before performing the experiment.

**Definition**:

A random experiment meets two key conditions:

* It has more than one possible outcome.
* The outcome cannot be predicted in advance with certainty, even if all conditions are repeated consistently.


**Examples**:

* **Tossing a coin:** The two possible outcomes are heads or tails, but the result is not predictable before the toss.
* **Rolling a die:** There are six possible outcomes (1 to 6), but any specific outcome cannot be known in advance.
* **Drawing a card from a shuffled deck:** Any one of 52 cards could be drawn, and it is uncertain which card will appear until the draw happens

**Key Terms**:

* **Outcome:** A possible result of a random experiment, such as “heads” in a coin toss.
* **Sample Space:** The set of all possible outcomes (e.g., {1,2,3,4,5,6} for a die roll).
* **Trial:** Each repetition of the random experiment.

### Sample Space:

A sample space in probability is the set of all possible outcomes of a random experiment.

* The sample space, often denoted by S or Ω, includes every unique outcome that could possibly occur in a given experiment.
* Each individual result is called an outcome or sample point.

**Examples**
1. Tossing a coin: Sample space S = {H, T} Where H is Head and T is trails
2. Rolling a six-sided die: S={1,2,3,4,5,6}.
3. Tossing two coins: S={HH,HT,TH,TT}.
4. Drawing a card from a deck: S={all 52 cards}.

### Event: Subset of S (Sample space)

**Definition**

* An event is any collection of one or more results from the sample space of a random experiment.
* Events are subsets of the sample space. For example, when rolling a die, the event "rolling an even number" consists of the outcomes {2, 4, 6}.

**Examples**

* **Tossing a coin:** The event "getting heads" is {H}.
* **Rolling a die:** The event "getting a number greater than 4" is {5, 6}.
* **Drawing a card:** The event "drawing a heart" includes all 13 heart cards in the deck.

**Types of events include:**

* **Simple event:** Contains only one outcome (e.g., rolling a 2).
* **Compound event:** Contains multiple outcomes (e.g., rolling an even number).
* **Impossible event:** Has no outcomes (probability 0).
* **Sure event:** Has all possible outcomes (probability 1).

**Event Operations**:

* **Union (A∪B):** Occurs if either event A or B (or both) happen.
* **Intersection (A∩B):** Occurs if both events A and B happen.
* **Complement (A′):** Occurs if event A does not happen.

**Complimentory Events:** if  (A∪B) = S and (A∩B) = 0 then A and B are complimentory events


#### 1. Discrete sample space:

**Definition**:

* The sample space is discrete if it contains outcomes that can be listed individually—either as a finite set or a countable sequence.
* Countable means the outcomes can be matched one-to-one with natural numbers, i.e., they can be counted, even if they are infinite in number.
* Each outcome in a discrete sample space is usually considered mutually exclusive and distinct.

**Examples**

1. Tossing a coin: S={H,T} (finite discrete sample space).
2. Rolling a die: S={1,2,3,4,5,6} (finite discrete sample space).
3. Tossing a coin until the first head appears: S={H,TH,TTH,TTTH,…} (countably infinite discrete sample space).

## Probability:

**Definition**

Mathematically, probability of an event  E is calculated as the ratio of favorable outcomes to the total number of possible outcomes:
 
P(E)= (Total number of possible outcomes) / (Number of favorable outcomes)

Examples
1. Tossing a fair coin: Probability of getting heads P(H)= 1/2 = 0.5
2. Rolling a six-sided die: Probability of rolling a 3 is P(3)= 1 / 6 

**Key Points**

* Probability ranges from 0 (impossible event) to 1 (certain event).
* Probability can be expressed as fractions, decimals, or percentages.
* Probability is foundational in fields such as statistics, science, finance, artificial intelligence, and everyday decision-making.

In brief, probability is the mathematical measure of how likely an event is to occur, helping predict outcomes in uncertain situations.
